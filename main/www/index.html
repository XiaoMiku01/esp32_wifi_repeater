    DNS 自定义解析

    列表中的域名由本机直接应答；未配置的域名照常转发到上游 DNS。仅对连接本机热点的设备生效。

      DNS 黑名单

      被拦截的域名回 NXDOMAIN（域名不存在）。每行一条，# 开头为注释。
      黑名单：不含通配符时精确匹配；* 匹配任意字符（含点），? 匹配单个字符。 例：*.example.com 拦截所有子域名（不含 example.com 本身）。
      例外：完整域名，不支持通配符；命中例外的域名不受黑名单影响。自定义解析优先于黑名单。

      域名与证书

      域名- 证书来源- 主题- 签发者- 有效期- SAN-

      新证书只对之后的新连接生效。修改域名时，DNS 自定义解析中的旧域名条目会自动改为新域名。

        https://…

        匹配规则：不区分请求方法和大小写，忽略结尾斜杠和查询串；路径中任意位置整段出现即命中， 设置 /abc 时 /abc、/a/abc、/abc/x、/a/abc/x 都会命中（/xabc、/abcx 不命中），多条命中时取最长的一条。

        配置备份（YAML）
        
      
        导出文件包含 Wi-Fi 密码和网页上传的私钥（明文），请妥善保管。
        导入时，文件中出现的段（wifi、dns、dns_blacklist、h2_site、h2_routes）会整体替换设备上对应的配置，未出现的段保持不变；
        wifi 段最后应用，改了热点时当前连接会断开。
